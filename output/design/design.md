# 能力管理平台 - 设计基线

## 一、文档概述

### 1.1 项目背景

在桂教通平台上建设能力管理模块，作为平台级能力开放枢纽。支持厂商入驻 → 能力上架 → 应用授权 → 接口申请审批 → 调用 → 数据同步的全链路，服务三类角色：机构管理员、桂教通超管、开发者管理员。一期一次交付全部功能。

### 1.2 设计目标

- 定义完整的产品事实基线，作为 PRD 与 Prototype 的唯一事实源
- 覆盖 xlsx 原始 72 个功能点 + 对齐阶段确认的运营统计模块 + 数据同步详细流程
- 以 8 月底上线为目标，兼顾完整性与落地效率

## 二、范围与建设方式

### 2.1 建设范围

| 模块 | 核心功能 | 涉及角色 |

## 四、模块定义

### 4.1 厂商管理模块

- **职责**：覆盖厂商从入驻邀请到合作全生命周期管理，包括厂商信息维护、联系跟进、合作状态变更
- **包含页面**：厂商列表页、新增/编辑厂商页、厂商详情页
- **涉及角色**：机构管理员（本机构厂商）、桂教通超管（全平台厂商）

### 4.2 API 接口管理模块

- **职责**：覆盖机构自建 API 接口的全生命周期管理，包括接口定义、接口文档、应用授权
- **包含页面**：接口列表页、新增/编辑接口页、接口文档查看页、应用授权页
- **涉及角色**：机构管理员（本机构接口）、桂教通超管（全平台接口）

### 4.3 接口申请与审批模块

- **职责**：管理外部开发者对本机构/平台接口的申请记录与审批流程
- **包含页面**：接口申请记录列表页、申请审批页、申请记录查看页
- **涉及角色**：机构管理员、桂教通超管、开发者管理员

### 4.4 厂商注册接口模块

- **职责**：厂商自助注册接口到平台，并经过审批后上线，支持接口上下线全生命周期
- **包含页面**：厂商注册接口列表页、厂商注册接口审批页
- **涉及角色**：机构管理员（机构级审批）、桂教通超管（平台级审批）、开发者管理员（注册与管理）

### 4.5 运营统计模块

- **职责**：提供平台运营数据看板，覆盖接口、厂商、应用、数据同步多维度统计
- **包含页面**：运营统计看板页
- **涉及角色**：机构管理员（本机构数据）、桂教通超管（全平台数据）

### 4.6 租户管理模块

- **职责**：管理桂教通平台上的租户（机构/学校），支持租户创建、导入、停用/启用
- **包含页面**：租户列表页、新增/编辑租户页
- **涉及角色**：桂教通超管

### 4.7 开发者账号模块

- **职责**：管理厂商方企业信息与子账号体系
- **包含页面**：企业信息管理页（P16）、企业子账号管理页（P17，新增子账号改为弹窗）
- **涉及角色**：开发者管理员

### 4.8 开发者接口中心模块

- **职责**：面向开发者管理员提供接口浏览、文档查看、接口申请能力
- **包含页面**：开发者接口列表页、开发者接口文档页、开发者接口申请页
- **涉及角色**：开发者管理员

### 4.9 数据同步模块

- **职责**：管理桂教通平台与厂商业务系统之间的双向数据同步，包括申请、审批、签字授权、任务执行与监控
- **包含页面**：数据同步申请列表页、数据同步申请页、数据同步审批页、数据同步签字授权页、数据同步查看页
- **涉及角色**：桂教通超管、开发者管理员

### 4.10 接口调用记录模块

- **职责**：记录各厂商调用桂教通平台接口的调用流水（调用时间、接口名称、厂商名称、调用应用、应用ID、调用结果、状态码、耗时），支持按接口名称/厂商名称/调用结果筛选与汇总统计
- **包含页面**：接口调用记录页
- **涉及角色**：桂教通超管

## 五、核心业务流程

### 5.1 厂商入驻与合作流程

```text
[机构管理员/桂教通超管]                [厂商方]
       │                                  │
       ├─ 新增厂商或邀请厂商 ──────────→ 厂商收到邀请链接
       │                                  ├─ 填写厂商信息
       │                                  └─ 提交注册
       ├─ 确认联系（记录联系状态）
       ├─ 确认合作 ──────────────────→ 系统自动创建租户
       │                                  └─ 厂商管理员可登录开发者平台
       ├─ 取消合作 ──────────────────→ 禁用租户登录
       └─ 重新合作 ──────────────────→ 恢复租户登录
```

### 5.2 API 接口授权流程

```text
[机构管理员/桂教通超管]
       │
       ├─ 新增/编辑接口定义
       ├─ 发布接口
       ├─ 应用授权（选择接口→选择应用→建立授权关系）
       └─ 接口停用/启用
```

### 5.3 接口申请与审批流程

```text
[开发者管理员]                    [机构管理员/桂教通超管]
       │                                  │
       ├─ 浏览接口列表
       ├─ 提交接口申请（含白名单域名）──────────────→ 收到申请通知
       │                                  ├─ 审核（通过/不通过）
       │                                  │   ├─ 通过 → 授权完成
       │                                  │   └─ 不通过 → 填写驳回原因
       │◄─────────────────────────────────┘
       └─ 查看申请记录
```

### 5.4 厂商注册接口审批流程

```text
[开发者管理员]                      [审批方]
       │                              │
       ├─ 注册接口
       │   ├─ 注册来源：机构 ──────→ 机构管理员审批
       │   │                          ├─ 通过 → 接口上线
       │   │                          └─ 驳回 → 可重新编辑
       │   │
       │   └─ 注册来源：桂教通 ────→ 桂教通超管审批
       │                              ├─ 通过 → 接口上线
       │                              └─ 驳回 → 可重新编辑
       │
       └─ 接口上线后：可操作下线、重新上线
```

### 5.5 数据同步流程

```text
[开发者管理员]                    [桂教通超管]
       │                                  │
       ├─ 提交数据同步申请 ──────────→ 审核申请
       │                                  ├─ 驳回 → 可重新编辑
       │                                  └─ 通过
       │                                      │
       │                                  ┌─ 签字授权
       │                                  │   ├─ 确认数据范围与安全责任
       │                                  │   └─ 签署
       │                                  │
       │                                  ├─ 分配 AppKey/SecretKey（流向二）
       │                                  │
       │                                  └─ 系统创建同步任务
       │                                      ├─ 执行中 → 完成/失败 → 可重试
       │                                      └─ 记录同步日志
       │◄─────────────────────────────────────────┘
       └─ 查看同步详情与日志
```

## 九、规则与状态定义

### 9.1 厂商合作状态机

```text
[未合作] ──确认合作──→ [合作中] ──取消合作──→ [已取消]
                           ↑                    │
                           └──重新合作───────────┘
```

- 确认联系：不改变合作状态，仅记录联系状态为"已联系"
- 确认合作前提：已确认联系
- 确认合作后：系统自动创建租户，厂商管理员可登录开发者平台
- 取消合作后：厂商管理员手机号不可登录开发者平台
- 重新合作后：恢复厂商管理员登录权限

> 注：厂商详情页（P03）不提供"取消合作"按钮，取消合作仅可在厂商列表（P01）操作。

### 9.2 接口状态机

```text
[启用] ←──→ [停用]
```

- 停用/启用前均需弹窗二次确认
- 停用后接口不可被调用，已授权应用不受影响但调用失败

### 9.3 接口申请状态机

```text
[未审核] ──审批──→ [已审核]
```

- 审批结论：通过/不通过
- 不通过时审核说明必填
- 通过后：自动为申请方应用建立接口授权关系

### 9.4 厂商注册接口状态机

```text
[待审批] ──审批通过──→ [已上线] ←──→ [已下线]
    │                      │
    └──审批不通过──→ [已驳回] ──重新编辑──→ [待审批]
```

- 审批流程（按注册来源）：
  - 机构注册 → 机构管理员审批 → 通过后自动上线
  - 桂教通注册 → 桂教通超管审批 → 通过后自动上线
- 驳回后开发者管理员可重新编辑重新提交
- 上线/下线操作需二次确认

### 9.5 数据同步状态机

```text
[待审批] ──审批通过──→ [待签字] ──签字授权──→ [待执行] ──执行──→ [执行中] ──完成──→ [成功]
    │                       │                      │                │
    └──审批不通过──→ [已驳回]  └─签字拒绝──→ [已拒绝]            └──失败──→ [失败] ──重试──→ [待执行]
                                                                                │
                                                                                └──取消──→ [已取消]
```

- 驳回后开发者管理员可重新编辑提交
- 签字授权不可跳过，不可撤回
- 签字后自动创建同步任务
- 失败后可手动重试

### 9.6 租户状态机

```text
[启用] ←──→ [停用]
```

- 停用后租户无法登录，关联的数据同步任务暂停
