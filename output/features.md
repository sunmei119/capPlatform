# 能力管理平台 - 功能清单

## 一、说明

- 本清单依据 `output/prototype/index.html` 菜单树、`output/design/design.md` 页面设计清单与模块定义整理。
- 角色：**机构管理员**（组织中心 → 能力管理）、**桂教通超管**（超管后台 → 能力管理）、**开发者管理员**（开发者后台 → 接口中心）。
- 一级菜单 / 二级菜单与原型侧栏一致；机构管理员侧栏为顶层菜单（无一级包裹），一级菜单栏标注「—」。
